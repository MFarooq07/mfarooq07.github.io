--- title: "Limit order Book" excerpt: "Limit order book: Efficient implementation of matching buyers with sellers.
" collection: portfolio --- A lightweight, open-source matching engine that brings the inner workings of an electronic financial exchange to life. This project ingests dynamic streams of buy and sell orders, sorts them into organized bid/ask queues, and pairs buyers and sellers instantly whenever prices overlap. By enforcing standard price-time priority rules and handling order lifecycle events like cancellations and partial fills, it provides a functional backend simulation of how modern stock and cryptocurrency trading platforms operate.
